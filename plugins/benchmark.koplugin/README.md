# RenderText 性能基准测试插件

## 功能描述

这是一个专门针对 KOReader 最新 `rendertext_fast` 模块的性能测试插件。该插件能够对比新旧文本渲染实现的性能差异，生成详细的测试报告。

## 主要特性

### 🚀 性能测试功能
- **快速测试**: 使用英文和中文短句进行基础性能对比
- **完整性能测试**: 使用6种不同类型的文本样本进行全面测试
- **批量渲染测试**: 专门测试批量文本渲染性能

### 📊 测试维度
- 文本尺寸计算性能 (`sizeUtf8Text`)
- 文本渲染性能 (`renderUtf8Text`)
- 子文本获取性能 (`getSubTextByWidth`)
- 批量渲染性能 (`renderTextBatch`)

### 📄 报告生成
- 生成详细的性能对比报告
- 支持直接在 KOReader 中查看报告
- 自动保存测试结果到数据目录
- 包含性能提升倍数和效率分析

## 测试样本

插件使用多种文本类型进行测试：

1. **ASCII文本**: 英文短句和长句
2. **CJK文本**: 中文短句和长句  
3. **混合文本**: 中英文混合内容
4. **特殊字符**: 符号和数学字符

## 使用方法

### 通过菜单访问
1. 在 KOReader 中打开任意文档
2. 点击菜单 → More tools → 渲染性能测试
3. 选择需要的测试类型：
   - **快速测试**: 2分钟内完成基础对比
   - **完整性能测试**: 5-10分钟完成全面测试
   - **批量渲染测试**: 测试批量处理性能
   - **查看最新报告**: 打开最近的测试报告

### 报告查看
- 测试完成后会自动生成 `.txt` 格式的报告
- 报告保存在 KOReader 数据目录
- 可通过"查看最新报告"功能直接在阅读器中打开

## 报告内容

### 性能对比报告包含
- 测试环境信息
- 各种文本样本的详细测试结果
- 原版 vs 新版实现的性能对比
- 性能提升倍数和操作频率
- 综合性能提升总结

### 批量渲染报告包含
- 批量处理配置信息
- 原版逐个渲染 vs 新版批量渲染对比
- 时间节省和效率提升分析

## 预期性能提升

根据 `rendertext_fast` 模块的设计目标：
- **文本渲染性能**: 200-500% 提升
- **批量处理**: 显著减少重复开销
- **智能回退**: 确保兼容性的同时最大化性能

## 技术实现

- 使用高精度时钟进行性能测量
- 预热机制确保测试准确性
- 多轮迭代减少测量误差
- 自动错误处理和回退机制

## 注意事项

1. 测试过程中请勿进行其他操作以确保结果准确性
2. 首次运行可能需要更长时间进行初始化
3. 报告文件会自动命名包含时间戳避免覆盖
4. 如果新版实现不可用，会自动使用原版作为对比基准
